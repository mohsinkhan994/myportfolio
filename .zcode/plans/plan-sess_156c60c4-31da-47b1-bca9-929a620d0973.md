## Holographic 3D Portfolio — Implementation Plan

### The concept
A fixed full-viewport **WebGL scene** sits behind all your content (replacing the current matrix-rain canvas). At its center floats a **rotating wireframe "terminal cube"** (your code/systems as a glowing hologram), orbited by a ring of **skill chips** (Java, Spring Boot, React, Python, FastAPI, RAG, Kafka, Docker, K8s, PostgreSQL…), all inside a drifting **green particle field**. Your existing content panels float on top, restyled as **holographic glass** — so it reads as "scrolling through a 3D hologram world" without sacrificing readability.

- **Mouse move** → camera parallax (the whole scene subtly shifts toward your cursor)
- **Scroll** → camera dollies + the orbit tilts, so the background evolves as you move through sections (the "flying through 3D space" feel)
- **Idle** → cube + chip ring rotate continuously; particles drift
- Existing shell-prompt dividers, numbered headings, terminal chrome, and ALL section text are untouched

### Dependencies
- **Add `three`** only (no `@react-three/fiber`, no drei). Vanilla Three.js in a `useEffect` — fully compatible with React 17 / react-scripts 4, no peer-dep conflicts.
- Install via `npm install three`.

### Files

**NEW — `src/components/portfolio/components/HoloScene.jsx`**
Self-contained component: creates a `<canvas className="pf-holo">`, builds the scene in `useEffect`:
- `PerspectiveCamera` (FOV 60), `WebGLRenderer({ alpha:true, antialias:true })`, pixel-ratio capped at 2
- **Central object**: `BoxGeometry` wireframe via `LineSegments(EdgesGeometry)` in glowing green + a faint inner translucent cube for depth
- **Orbiting chips**: ~10 `PlaneGeometry` sprites textured with `CanvasTexture` (text labels drawn on a 2D canvas), parented to a rotating `Group` in a ring around the cube
- **Particle field**: ~700 green `Points` in a large sphere for depth (carries a hint of the old matrix vibe)
- Lights: ambient + green point light near cube + amber accent point light; subtle green fog
- Single `requestAnimationFrame` loop: rotate cube, rotate chip ring, parallax camera toward mouse (lerped), tie camera dolly + group tilt to `window.scrollY`
- **Safety/cleanup**: pause on `visibilitychange` (tab hidden), honor `prefers-reduced-motion` (render one static frame, no loop), dispose geometries/materials/renderer + remove listeners on unmount

**MODIFIED — `src/components/portfolio/Portfolio.jsx`**
- Swap `<MatrixRain />` → `<HoloScene />` (MatrixRain.jsx stays in repo, just not rendered — keeps it reversible)
- Keep `<div className="pf-scanlines">` and `<div className="pf-vignette">` (they layer nicely over the 3D)
- Everything else (Header, all sections, Footer) unchanged

**MODIFIED — `src/components/portfolio/Portfolio.css`** (additive)
- Reuse `.pf-matrix` z-layer slot for the new canvas (`.pf-holo` at z-index 0, fixed, full-viewport)
- **Holographic panel upgrade**: stronger green glow on `.pf-section` / `.pf-hero` borders, a subtle border "hologram flicker" keyframe, slightly more translucent panel fills so the 3D glows through the glass
- A touch more translucency on panels (still readable — text contrast preserved)
- No changes to the `pf-` class names, section `id`s, or the CSS-generated shell prompts/numbered headings — so the existing theme logic keeps working

**NOT touched** (content preserved exactly): `Hero.jsx`, `About.jsx`, `Experience.jsx`, `Projects.jsx`, `Skills.jsx`, `Education.jsx`, `Contact.jsx`, `Footer.jsx`, `data.js`, `app.scss`, `public/index.html`. No text, no links, no structure changes.

### Performance & accessibility
- One rAF loop, pause on tab-hidden, reduced-motion static frame
- Pixel-ratio cap 2, antialias on, modest geometry counts (~700 particles, 10 chips, 1 cube)
- Canvas is pure decoration: `aria-hidden`, pointer-events pass through to content
